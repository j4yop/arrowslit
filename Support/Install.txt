Arrowslit 0.1.0
=============

A local-only notch utility for macOS 14 or later.
Universal build: Apple Silicon and Intel.

Install
-------
1. Drag Arrowslit.app into the Applications folder.
2. Open Applications, right-click Arrowslit, and choose Open.
   Arrowslit is ad-hoc signed (not notarized with an Apple Developer ID),
   so macOS will ask you to confirm the first launch. This is normal.
3. Grant Camera, Calendars, or Reminders only if you want those features.

If macOS says the app is damaged
--------------------------------
Open Terminal and run:

    xattr -dr com.apple.quarantine /Applications/Arrowslit.app

Privacy
-------
Arrowslit has no account, analytics, or network access.
Clipboard history, notes, the file tray and timers stay on this Mac.
