Arrowslit __VERSION__
==================

A quiet control surface for the MacBook notch.
Requires macOS 14 (Sonoma) or later. Universal: Apple Silicon and Intel.

This build is signed with a local certificate but is not notarized by Apple.
macOS will block the first launch. That is expected: it is not a damaged
download, and it does not mean the app is broken. Choose one of the two
paths below.

Homebrew (recommended)
----------------------
    brew trust j4yop/tap && brew install --cask j4yop/tap/arrowslit

The cask removes the quarantine flag after installation, so Arrowslit opens
normally. Homebrew 7 asks you to trust the third-party tap once.

Manual install
--------------
1. Drag Arrowslit into Applications.
2. Open Applications and double-click Arrowslit. macOS will say it cannot
   verify the app. Click Done.
3. Do one of these:

   a. System Settings -> Privacy & Security -> scroll to the Security
      section -> "Open Anyway" next to Arrowslit, then confirm.

   b. Terminal (works on every macOS version, including macOS 26/27):

        xattr -dr com.apple.quarantine "/Applications/Arrowslit.app"
        open "/Applications/Arrowslit.app"

4. Arrowslit's Settings window opens. Choose the features you want and close
   the window; Arrowslit stays running in the notch.

If macOS says "Arrowslit is damaged and can't be opened", that is the same
quarantine block, not a corrupt file. Use the Terminal command in step 3b.
You can verify the download first (the .sha256 file must sit next to the DMG):

    shasum -a 256 -c Arrowslit-__VERSION__.dmg.sha256

Permissions
-----------
Calendar, Reminders and Camera permissions are remembered by macOS for this
installed copy. Press Connect once in Settings and allow access; macOS keeps
that choice across quitting and reopening. Arrowslit never asks in the
background. Use one installed copy in Applications.

Updating an unnotarized build can ask once more. A future Developer ID /
notarized release will remove this prompt entirely.

Using it
--------
Hover the top of the screen for 0.4 seconds, or click the strip, to open.
Click the slit in the menu bar if the strip is hard to reach. Settings can be
opened again from the menu bar or by reopening Arrowslit.

Privacy
-------
Arrowslit has no account, analytics, or telemetry. Clipboard history, notes,
the file tray and timers stay on this Mac.
